# Neo Builder User Manual - 科学技術

本書は科学技術陣営を選んだプレイヤー向けの手引きです. アイテム一覧、個別仕様は [ITEMS.md](./ITEMS.md) を参照してください. 

## 1. 世界

サーバには 2 つのワールドがあります. 

| ワールド | 役割 |
|---|---|
| オーバーワールド | 工業と生活の世界. マシン建設、採掘、一括破壊、追加鉱石はこちら |
| アドベンチャーワールド | 戦闘とダンジョンの世界. 塔や地下石室が新規チャンクにランダム生成 |

> [!NOTE]
> あなたはオーバーワールドで工業インフラを築き、ダンジョンワールドで財貨と戦利品を稼ぐ "開拓者" です 

### 技術陣営ルール

* 初回ログイン時（または `/tech`）に 科学技術 / 魔法技術 を 1 回だけ選択します. 
* 科学陣営は呪文書や杖などの魔術アイテムを拾得、設置、所持できません. 逆に魔法陣営は科学アイテムを使えません. 
* 陣営を変更するにはお金がかかります.

## 2. クイックスタート

1. `/tech` で 科学技術 を選択
2. `/job` で職業を選択 — 科学陣営は Scientist 固定 です
3. オーバーワールドでエンジン → キネシスパイプ → マシンを配線
4. アドベンチャーワールドでダンジョンを回ってお金と素材を稼ぐ

> [!NOTE]
> 武器制限: 科学陣営は 剣、弓、ボウガン、槍を使用できません. 斧、ピッケル、クワ、シャベルなどのツール類は使用可能です. 戦闘は魔法陣営の仲間と連携しましょう.

### コマンド一覧

| コマンド | 説明 |
|---|---|
| `/tech` | 技術陣営の選択 GUI を開く（未選択時のみ） |
| `/balance` (`/bal`, `/money`) | 所持金残高の確認 |
| `/pay <player> <amount>` | 送金 |

## 3. 基本メカニクス

### エネルギー: MJ

* 発電設備（エンジン/発電機/ソーラー）が生み出すエネルギー単位は MJ. 
* マシンは内部バッファに MJ を蓄えて動作します. 
* 電力の流れ: 発電設備 → 隣接マシンへ直結、または キネシスパイプ/ケーブル経由で遠隔マシンへ. 

### 燃料の供給

* 燃焼系エンジン、発電機は隣接するチェスト等のインベントリから燃料を自動消費します. 
* 燃焼エンジンは「溶岩バケツ」のほか、隣接大釜の溶岩も燃料にできます（流体パイプで自動給油可能）. 

### 流体（液体）輸送

* 液体のコンテナは 大釜（カルドロン） です. 水位 1段 = 333 mB（満杯 999 mB）. 
* 流体パイプは隣接大釜から 333 mB ずつ引き、パイプ網の先の空き大釜へ運びます. 
* ポンプは直下の水源を汲み上げ、隣接大釜へ注水します. 

### マシンの入出力ルール

* 入力: 隣接するインベントリ（チェスト等）から素材を自動で取り込む. 
* 出力: まず真上のインベントリへ → だめなら側面のインベントリへ → それもだめならその場にドロップ. 
* 回収: マシン、パイプは破壊するとカスタムアイテムとしてドロップする（レンチは回収用ツール）. 

### 環境負荷（EFP）と災害

* クァーリーの掘削はブロックごとに環境負荷（EFP）を +1 蓄積します. 
* EFP が閾値（初期値 10,000）を超えると、定期的な判定で 災害 が発生する可能性あり. 
* 災害が起きると、`world_life` にいるランダムなプレイヤー周辺に強化モブ（HP2倍、攻撃1.5倍、速度1.2倍のゾンビ/スケルトン/クリーパー/ウィッチ）が襲撃します. 
* EFP は毎分少しずつ自然減衰します. `/nb efp` で現在値を確認できます. 

## 4. 工業化レシピ（加工フロー）

バニラのクラフトレシピは追加されていません. 加工は専用マシンで行います. 

### 鉱石2倍化（粉砕 → 精錬）

| 工程 | 入力 → 出力 |
|---|---|
| 粉砕機 | 鉄鉱石/深層鉄鉱石/原石 → 鉄粉×2 |
| 粉砕機 | 金鉱石/深層金鉱石/ネザー金鉱石/原金 → 金粉×2 |
| 粉砕機 | 銅鉱石/深層銅鉱石/原銅 → 銅粉×2 |
| 粉砕機 | ダイヤ鉱石 → ダイヤ×2 / 石炭鉱石 → 石炭×2 / エメラルド鉱石 → エメラルド×2 |
| 粉砕機 | ラピス鉱石 → ラピス×4 / レッドストーン鉱石 → レッドストーン×6 / クォーツ鉱石 → クォーツ×2 |
| 粉砕機 | 古代の残骸 → ネザライトスクラップ×2 |
| かまど（バニラ） | 鉄粉/金粉/銅粉 → 各インゴット |

※粉砕は 1回 400 MJ（100tick）. 入力は側面チェスト、出力は上→側面チェスト. 

### 圧縮機、抽出機、精製所

| マシン | レシピ | 消費 |
|---|---|---|
| 圧縮機 | 石炭×9 → 石炭ブロック | 60tick/回 |

### 電気かまど系、自動作業台

| マシン | 処理速度 | 消費 |
|---|---|---|
| 鉄かまど | 80tick/個 | 5 MJ/t |

| 誘導かまど | 40tick/個 | 5 MJ/t |

## 5. 採取資源

| 資源 | 生成条件 | 用途 |
|---|---|---|
| ウラン鉱石 | Y32未満（エメラルド鉱石の外見） | 精製ウラン、ウランセル、原子力の元 |
| イリジウム鉱石 | 深層に極稀（ダイヤ鉱石の外見） | イリジウム板（最上位素材） |
| ゴムの木 | 地表に稀に生成（ジャングル原木） | 樹液採取具 or 抽出機でゴム |
| 原油脈 | 地表に稀な黒い池 | 原油バケツ → 精製所で燃料バケツ |

### 一括破壊（オーバーワールド限定機能）

対応ツールで掘ると鉱脈、木をまとめて破壊（上限128ブロック、耐久消費、分割処理）:

| ツール | 対象 |
|---|---|
| 斧 | 原木 + 葉（CutAll） |
| ツルハシ | 鉱石鉱脈、古代の残骸（MineAll） |
| シャベル | 土、砂、砂利、泥系（DigAll） |

## 6.5. CQ系ダンジョン（注意）

`world_dungeon` には既存の塔/地下石室に加え、海賊船、砂漠の砦、氷原の城、ネクロマンサーの城等が生成され、武装CQモブと固有ボス（海賊船長/ファラオ/ウォーカーキング/ネクロマンサー等）が待ち構えます. Scientistは剣、弓、槍が使えないため単独攻略は困難です — 魔法陣営の仲間に討伐を任せ、報酬（バッジ、DL、CQ武器）は取引で分け合いましょう. 詳細は魔法側マニュアル [USER_MANUAL_MAGIC.md](./USER_MANUAL_MAGIC.md) §5.5 を参照. 

## 7. ダンジョンとボス（world_dungeon）

新規チャンクに約3%の確率で構造物が生成されます. 

* 塔（TOWER）: 石レンガの3層構造. 各層にスポナー（1層ゾンビ / 2層スケルトン）、頂上に宝箱. 約15%の確率で頂上にボスも出現. 
* 地下石室（CRYPT）: 地下10ブロックの11×11石室. 洞窟グモスポナー、宝箱2つ、感圧板+TNTのトラップ付き. 
* 宝箱の中身: 鉄、金インゴット、矢、パン、経験値瓶、DLコイン（1〜4枚）、約15%で ヴォイドコア. 

### カタクリズム、ガーディアン（レイドボス）

HP400の強化ラヴァジャー. 周囲を回る「ブレードリング」演出付き. 

* HP50%以下: 周囲プレイヤーへ落雷を呼ぶ
* HP25%以下: 自爆的な爆発攻撃を追加
* 常時: 正面のプレイヤーにレーザー風ダメージ
* 討伐報酬: ヴォイドコア + 討伐者に 5,000 DL

## 8. 経済（DL）

* 初期残高: 1,000 DL. `/balance` で確認、`/pay` で送金. 
* 収入源: ダンジョン宝箱のDLコイン、ボス討伐、（今後の取引要素）. 
* 用途: 陣営、職業リセット費用など. 

## 9. よくある注意点

* 科学アイテム、マシン、パイプ、素材の全一覧と `/nb give` コマンドは [ITEMS.md](./ITEMS.md) 参照. 
* 魔法タグのアイテムは拾えません（拾おうとすると拒否メッセージ）. 
* マシンは毎tick全体をラウンドロビンで処理するため、大量設置時は1基あたりの処理間隔が多少伸びます（TPS保護）. 
* パイプ網はBFSで探索され上限512ノードまで. 超巨大網は分割してください.
