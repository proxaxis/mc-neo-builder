# NeoBuilder ユーザーマニュアル【科学技術】

> 「エンジン・パイプ・マシンによる自動化。産業で世界を変えろ」

本書は **科学技術（SCIENCE）陣営** を選んだプレイヤー向けの手引きです。
アイテム全一覧・個別仕様は [ITEMS.md](./ITEMS.md) を参照してください。

---

## 1. 世界観と2つのワールド

サーバにはプラグインが自動生成する2つのワールドがあります。

| ワールド | 役割 |
|---|---|
| `world_life` | 工業・生活ワールド。マシン建設・採掘・一括破壊・追加鉱石はこちら |
| `world_dungeon` | 戦闘・ダンジョンワールド。塔や地下石室が新規チャンクにランダム生成 |

あなたは生活ワールドで工業インフラを築き、ダンジョンワールドで財貨と戦利品を稼ぐ「開拓者」です。

### 技術陣営ルール

- 初回ログイン時（または `/tech`）に **科学技術 / 魔法技術** を1回だけ選択します。
- 科学陣営は「MAGIC」タグのアイテム（呪文書・ワンド等）を**拾得・設置・所持できません**。逆に魔法陣営は科学アイテムを使えません。
- 変更は原則不可（有償リセット機構あり・DL消費）。

## 2. はじめかた（クイックスタート）

1. `/tech` で **科学技術** を選択
2. `/job` で職業を選択（後述。科学と職業は独立なので好きな職業でOK）
3. `world_life` でエンジン → キネシスパイプ → マシンを配線
4. `world_dungeon` でダンジョンを回って DL と素材を稼ぐ

### コマンド一覧

| コマンド | 説明 |
|---|---|
| `/tech` | 技術陣営の選択GUIを開く（未選択時のみ） |
| `/job` | 職業選択GUIを開く |
| `/skill` | 習得スキル一覧表示 |
| `/skill <id>` | スキル発動（例: `/skill warcry`） |
| `/skill learn <id>` | 戦士スキルツリーへSP割り振り（Warriorのみ） |
| `/balance` (`/bal`, `/money`) | DL残高の確認 |
| `/pay <player> <amount>` | DL送金 |
| `/nb give <アイテムID>` | カスタムアイテム入手（OP専用） |

### 職業（/job）

職業は陣営と独立しており、科学陣営でも全職業を選べます。詳細は §6 を参照。

## 3. 基本メカニクス

### エネルギー: MJ

- 発電設備（エンジン/発電機/ソーラー）が生み出すエネルギー単位は **MJ**。
- マシンは内部バッファに MJ を蓄えて動作します。
- 電力の流れ: **発電設備 → 隣接マシンへ直結、または キネシスパイプ/ケーブル経由で遠隔マシンへ**。

### 燃料の供給

- 燃焼系エンジン・発電機は**隣接するチェスト等のインベントリ**から燃料を自動消費します。
- 燃焼エンジンは「溶岩バケツ」のほか、**隣接大釜の溶岩**も燃料にできます（流体パイプで自動給油可能）。

### 流体（液体）輸送

- 液体のコンテナは **大釜（カルドロン）** です。水位 1段 = **333 mB**（満杯 999 mB）。
- 流体パイプは隣接大釜から 333 mB ずつ引き、パイプ網の先の空き大釜へ運びます。
- ポンプは直下の水源を汲み上げ、隣接大釜へ注水します。

### マシンの入出力ルール

- **入力**: 隣接するインベントリ（チェスト等）から素材を自動で取り込む。
- **出力**: まず真上のインベントリへ → だめなら側面のインベントリへ → それもだめならその場にドロップ。
- **回収**: マシン・パイプは破壊するとカスタムアイテムとしてドロップする（レンチは回収用ツール）。

### 環境負荷（EFP）と災害

- クァーリーの掘削はブロックごとに環境負荷（EFP）を +1 蓄積します。
- EFP が閾値（初期値 10,000）を超えると、定期的な判定で **災害** が発生する可能性あり。
- 災害が起きると、`world_life` にいるランダムなプレイヤー周辺に強化モブ（HP2倍・攻撃1.5倍・速度1.2倍のゾンビ/スケルトン/クリーパー/ウィッチ）が襲撃します。
- EFP は毎分少しずつ自然減衰します。`/nb efp` で現在値を確認できます。

## 4. 工業化レシピ（加工フロー）

バニラのクラフトレシピは追加されていません。加工は**専用マシン**で行います。

### 鉱石2倍化（粉砕 → 精錬）

| 工程 | 入力 → 出力 |
|---|---|
| 粉砕機 | 鉄鉱石/深層鉄鉱石/原石 → 鉄粉×2 |
| 粉砕機 | 金鉱石/深層金鉱石/ネザー金鉱石/原金 → 金粉×2 |
| 粉砕機 | 銅鉱石/深層銅鉱石/原銅 → 銅粉×2 |
| 粉砕機 | ダイヤ鉱石 → ダイヤ×2 / 石炭鉱石 → 石炭×2 / エメラルド鉱石 → エメラルド×2 |
| 粉砕機 | ラピス鉱石 → ラピス×4 / レッドストーン鉱石 → レッドストーン×6 / クォーツ鉱石 → クォーツ×2 |
| 粉砕機 | 古代の残骸 → ネザライトスクラップ×2 |
| かまど（バニラ） | 鉄粉/金粉/銅粉 → 各インゴット |

※粉砕は 1回 400 MJ（100tick）。入力は側面チェスト、出力は上→側面チェスト。

### 圧縮機・抽出機・精製所

| マシン | レシピ | 消費 |
|---|---|---|
| 圧縮機 | 石炭×9 → 石炭ブロック | 60tick/回 |
| 圧縮機 | 生炭素繊維×2 → 生炭素メッシュ | 60tick/回 |
| 抽出機 | ゴムの原木 → ゴム | 60tick/回 |
| 精製所 | 原油バケツ or 溶岩バケツ → 燃料バケツ | 10 MJ/t × 100tick |

### 電気かまど系・自動作業台

| マシン | 処理速度 | 消費 |
|---|---|---|
| 鉄かまど | 80tick/個 | 5 MJ/t |
| 電気かまど | 100tick/個 | 5 MJ/t |
| 誘導かまど | 40tick/個 | 5 MJ/t |
| 自動作業台 | 原木→板材×4、丸石→石（1秒周期） | 10 MJ/回 |

### 配線の組み立て例

```
[チェスト:石炭] → [スターリングエンジン] → [キネシスパイプ] → [粉砕機]
                                                        └→ [電気かまど]
```

```
[水源の上のポンプ] → [大釜(水)] → [流体パイプ] → [大釜(溶岩側は給油)]
[溶岩大釜] → [燃焼エンジン] → [キネシスパイプ] → [クァーリー]
```

```
[チェスト] → [抽出パイプ] → [輸送パイプ網] → [各所チェスト]
        └ 分岐したい場合はテレポートパイプ(周波数一致)でワイヤレス転送
```

```
[在庫チェスト] + [プロバイダーパイプ] …公開側
[受取チェスト] + [リクエストパイプ] …右クリックでGUI、クリックで取り寄せ
```

## 5. 採取資源（world_life 追加ワールド生成）

| 資源 | 生成条件 | 用途 |
|---|---|---|
| ウラン鉱石 | Y32未満（エメラルド鉱石の外見） | 精製ウラン・ウランセル・原子力の元 |
| イリジウム鉱石 | 深層に極稀（ダイヤ鉱石の外見） | イリジウム板（最上位素材） |
| ゴムの木 | 地表に稀に生成（ジャングル原木） | 樹液採取具 or 抽出機でゴム |
| 原油脈 | 地表に稀な黒い池 | 原油バケツ → 精製所で燃料バケツ |

### 一括破壊（全員使える生活ワールド限定機能）

`world_life` で対応ツールで掘ると鉱脈・木をまとめて破壊（上限128ブロック、耐久消費・分割処理）:

| ツール | 対象 |
|---|---|
| 斧 | 原木 + 葉（CutAll） |
| ツルハシ | 鉱石鉱脈・古代の残骸（MineAll） |
| シャベル | 土・砂・砂利・泥系（DigAll） |

## 6. 職業とスキル（/job）

`/job` で6職から1つ選択（1回のみ・リセットは有償）。モンスター撃破で経験値（Monster 10 / その他 3）を得てレベルアップ。LvUP毎に **SP+2・最大MP+5**。

| 職業 | パッシブ | スキル（/skill <id>） |
|---|---|---|
| Warrior | 近接 +20%。SP割振り可能な専用ツリー持ち | `warcry`（周囲に力付与/30s）`cleaverush`（扇形12ダメ/12s）`leapassault`（跳躍範囲攻撃/15s）`berserkmode`（強化15s・被弾+20%/90s） |
| Assassin | 移動+30%、背後攻撃2.5倍 | `shadowstep`（対象背後へ転移+次撃確定クリティカル/20s）`smokescreen`（透明5s+被弾半減/40s） |
| Guardian | 被ダメ-25%、移動-8% | `taunt`（周囲Mobのタゲ取得/15s）`fortress`（5s超軽減+味方耐性/45s） |
| Healer | — | `sanctuary`（10s回復領域・アンデッドにダメージ/40s）`resurrection`（周囲味方を10回復+毒/ウィザー解除/180s） |
| Mage | 魔法・毒・ドラゴンブレス耐性-20%、MP高速回復 | `meteorstrike`（MP40: 着弾爆発+25ダメ/45s）`frostnova`（MP25: 周囲凍結+鈍足/30s） |
| Archer | 唯一弓使用可、矢50%節約、距離でダメージ最大+80% | `rainofarrows`（指定地点へ矢20本の雨/25s）`piercingshot`（次射貫通+1.5倍/30s） |

戦士スキルツリー（`/skill learn <id>`、SP消費）: `heavyslash`（範囲追撃）`armbreaker`（装甲貫通）`execution`（トドメ強化）`bloodlust`（撃破時回復+加速）`battleharden`（被弾スタック軽減）`unchained`。

## 7. ダンジョンとボス（world_dungeon）

新規チャンクに約3%の確率で構造物が生成されます。

- **塔（TOWER）**: 石レンガの3層構造。各層にスポナー（1層ゾンビ / 2層スケルトン）、頂上に宝箱。約15%の確率で頂上にボスも出現。
- **地下石室（CRYPT）**: 地下10ブロックの11×11石室。洞窟グモスポナー、宝箱2つ、感圧板+TNTのトラップ付き。
- **宝箱の中身**: 鉄・金インゴット、矢、パン、経験値瓶、**DLコイン**（1〜4枚）、約15%で **ヴォイドコア**。

### カタクリズム・ガーディアン（レイドボス）

HP400の強化ラヴァジャー。周囲を回る「ブレードリング」演出付き。

- HP50%以下: 周囲プレイヤーへ落雷を呼ぶ
- HP25%以下: 自爆的な爆発攻撃を追加
- 常時: 正面のプレイヤーにレーザー風ダメージ
- 討伐報酬: **ヴォイドコア** + 討伐者に **5,000 DL**

## 8. 経済（DL）

- 初期残高: 1,000 DL。`/balance` で確認、`/pay` で送金。
- 収入源: ダンジョン宝箱のDLコイン、ボス討伐、（今後の取引要素）。
- 用途: 陣営・職業リセット費用など。

## 9. よくある注意点

- 科学アイテム・マシン・パイプ・素材の全一覧と `/nb give` コマンドは [ITEMS.md](./ITEMS.md) 参照。
- 魔法タグのアイテムは拾えません（拾おうとすると拒否メッセージ）。
- マシンは毎tick全体をラウンドロビンで処理するため、大量設置時は1基あたりの処理間隔が多少伸びます（TPS保護）。
- パイプ網はBFSで探索され上限512ノードまで。超巨大網は分割してください。
