# NeoBuilder ユーザーマニュアル【魔法技術】

> 「詠唱と呪文による超常の力。魔力で世界を変えろ」

本書は **魔法技術（MAGIC）陣営** を選んだプレイヤー向けの手引きです。
魔法は「機械」ではなく「職業・スキル・詠唱」を軸にしたプレイスタイルです。

---

## 1. 世界観と2つのワールド

| ワールド | 役割 |
|---|---|
| `world_life` | 生活ワールド。採取・一括破壊が可能な拠点ワールド |
| `world_dungeon` | 戦闘・ダンジョンワールド。魔法使いの主戦場。塔や地下石室が新規チャンクにランダム生成 |

魔法陣営は機械を持たない代わりに、**職業スキル・MP・詠唱呪文**でダンジョンを制覇します。

### 技術陣営ルール

- 初回ログイン時（または `/tech`）に **科学技術 / 魔法技術** を1回だけ選択します。
- 魔法陣営は「SCIENCE」タグのアイテム（エンジン・パイプ・マシン等）を**拾得・設置・所持できません**。
- 変更は原則不可（有償リセット機構あり・DL消費）。

## 2. はじめかた

1. `/tech` で **魔法技術** を選択
2. `/job` で職業を選択（Scientist は選択不可）。**呪文書・魔導書を使うなら Mage を選択すること**（他職でもOKだが書物は詠唱できない）
3. `world_dungeon` に赴き、ダンジョンでレベルと DL を稼ぐ
4. 詠唱（§4）をマスターして呪文を開放する

> **武器ルール**: 魔法陣営は **弓・ボウガン以外のすべての武器**（剣・斧・槍トライデント等）が使えます。弓・ボウガンを使えるのは **Archer のみ** です。

### コマンド一覧

| コマンド | 説明 |
|---|---|
| `/tech` | 技術陣営の選択GUIを開く |
| `/job` | 職業選択GUIを開く |
| `/skill` | 習得スキル一覧表示 |
| `/skill <id>` | スキル直接発動（例: `/skill frostnova`） |
| `/skill learn <id>` | 戦士スキルツリーへSP割り振り（Warriorのみ） |
| `/balance` (`/bal`, `/money`) | DL残高の確認 |
| `/pay <player> <amount>` | DL送金 |
| `/nb give <アイテムID>` | カスタムアイテム入手（OP専用） |

## 3. RPGシステム（職業・レベル・MP）

### レベルと経験値

- モンスター撃破で **+10 XP**、その他の生物で **+3 XP**、Archerの矢ヒットで **+2 XP**。
- レベルアップ（次Lvまで `100×現在Lv` XP）で **SP+2・最大MP+5・MP全回復**。
- `/skill` で自分のスキルと習得Lvを確認できます。

### MP（マナ）

- 全職に MP があり（初期最大100）、呪文系スキルのコストとして消費。
- **Mage は2秒毎に 2.0 回復**、他職は 0.5 回復。LvUPで最大値+5。
- MageのMPはアクションバーに常時表示されます。

### 職業一覧

魔法陣営が選択できるのは以下の6職です（`Scientist` は科学技術陣営専用で選択不可）。

| 職業 | パッシブ | スキル（/skill <id>） |
|---|---|---|
| Warrior | 近接 +20%。専用スキルツリー持ち | `warcry`（周囲味方に力、自分は力II 15s / CD30s）`cleaverush`（前方扇形12ダメ+弱体/12s）`leapassault`（跳躍→範囲8ダメ+鈍足/15s）`berserkmode`（力III+速度II 15s・被弾+20%/90s） |
| Assassin | 移動+30%、背後からの攻撃2.5倍 | `shadowstep`（視線先20mの対象背後へ転移+次の攻撃が確定クリティカル/20s）`smokescreen`（5s透明+モブのタゲ解除+被弾半減/40s） |
| Guardian | 被ダメ-25%、移動-8% | `taunt`（15m内モブのタゲを自分へ/15s）`fortress`（5s間ほぼ無敵化+周囲味方に耐性II/45s） |
| Healer | — | `sanctuary`（10s間の回復領域: 味方回復+アンデッドにダメージ/40s）`resurrection`（12m内の味方を10回復+毒・ウィザー解除/180s） |
| Mage | 魔法・毒・ドラゴンブレス被ダメ-20%、MP高速回復 | `meteorstrike`（MP40・CD45s）`frostnova`（MP25・CD30s）詳細は §4 |
| Archer | 唯一弓使用可能職。矢消費50%節約、距離30mで最大+80%ダメージ | `rainofarrows`（指定地点上空へ矢20本の雨/25s）`piercingshot`（5s以内の次射が貫通4+ダメ1.5倍/30s） |

> **弓・ボウガンは Archer 以外は使用不可**です（発射がキャンセルされます）。剣・斧・槍など他の武器は全職業で使用可能です。

### 戦士スキルツリー（Warrior限定）

`/skill learn <id>` でSPを割り振ります。

| スキル | 最大Lv | 効果 |
|---|---|---|
| `heavyslash` | 5 | 近接攻撃時に確率で周囲3mへ波及ダメージ |
| `armbreaker` | 3 | 装甲持ちの敵へのダメージ増加 |
| `execution` | 3 | HP30%以下の敵へのダメージ大幅増加 |
| `bloodlust` | 3 | 撃破時に体力回復+速度付与 |
| `battleharden` | 5 | 被弾毎に短時間スタックするダメージ軽減（最大20%） |
| `unchained` | 2 | ※効果は今後追加予定 |

## 4. 詠唱と呪文（Chant）

Mageの醍醐味。**呪文書・魔導書を持って右クリック**すると詠唱GUIが開きます。

### 詠唱のしかた

1. 書物を右クリック → 詠唱GUIが開く（Mage専用）
2. 上段に表示される **4つの目標ルーン** を、下段のボタンで **順番どおりにクリック**
3. ルーンは4種: **炎**（ブレイズパウダー）・**氷**（氷）・**雷**（グロウストーンダスト）・**地**（土）
4. 間違えると最初からやり直し。進行度はアクションバーの ◆◇ で確認可能
5. 制限時間（約10秒）内に完走すると呪文発動。GUIを閉じると詠唱中断

> 詠唱パターンは呪文ごとに固定なので、覚えれば瞬時に唱えられます。

### 書物と呪文対応表

| 書物 | give コマンド | 発動呪文 | 詠唱シーケンス |
|---|---|---|---|
| 呪文書 | `/nb give spellbook` | フロストノヴァ | 炎→雷→氷→氷 |
| 魔導書: フロスト | `/nb give grimoire_frost` | フロストノヴァ | 炎→雷→氷→氷 |
| 魔導書: メテオ | `/nb give grimoire_meteor` | メテオストライク | 氷→氷→地→地 |

### 呪文性能（/skill でも直接発動可能）

| 呪文 | MP | CD | 効果 |
|---|---|---|---|
| `frostnova` フロストノヴァ | 25 | 30s | 周囲6mの敵を凍結+強力な鈍足（6s）+6ダメージ |
| `meteorstrike` メテオストライク | 40 | 45s | 視線先40m以内の着弾点に爆発、半径8mに25ダメージ（1.5sの遅延） |

### 魔法アイテム一覧

| アイテム | give コマンド | 説明 |
|---|---|---|
| 呪文書 | `/nb give spellbook` | 詠唱開始の基本書物（フロストノヴァ） |
| ワンド | `/nb give wand` | 詠唱補助杖 |
| マナクリスタル | `/nb give mana_crystal` | MP回復アイテム |
| 魔導書: メテオ | `/nb give grimoire_meteor` | メテオストライクを解放する書物 |
| 魔導書: フロスト | `/nb give grimoire_frost` | フロストノヴァを解放する書物 |

> 書物の使用は **Mage限定**。また `/skill <id>` なら書物なしでも同じ呪文が撃てます（MPとクールダウンは共通）。

## 5. ダンジョン攻略（world_dungeon）

新規チャンクに約3%の確率で構造物が生成されます。

- **塔（TOWER）**: 3層の石塔。1層ゾンビ・2層スケルトンのスポナー、頂上宝箱。約15%で頂上にボス出現。
- **地下石室（CRYPT）**: 地下11×11の石室。洞窟グモスポナー、宝箱2つ。**中央通路の感圧板はTNTトラップ**なので注意。
- **宝箱の中身**: 鉄・金インゴット、矢、パン、経験値瓶、**DLコイン**（1〜4枚）、約15%で **ヴォイドコア**。

### カタクリズム・ガーディアン（レイドボス）

HP400・攻撃15の強化ラヴァジャー。周囲を剣が周回する「ブレードリング」演出が特徴。

- HP50%以下: 周囲のプレイヤーに落雷
- HP25%以下: 爆発攻撃を追加
- 正面に立つとレーザー風のダメージを受ける → **側面・背後から攻めるのが定石**
- 討伐報酬: **ヴォイドコア** + 討伐者に **5,000 DL**

### 攻略のコツ

- Mageなら `frostnova` で群れを鈍足化→`meteorstrike` で焼き払うのが基本コンボ。
- MP回復を待つ間は距離を取ること。詠唱は移動中でもGUIを閉じなければ継続。
- 弓は使えないので遠距離は呪文頼み。Healerとのパーティプレイが効果的。

## 5.5. Chocolate Quest 系ダンジョン・Mob・ボス

`world_dungeon` には塔・地下石室に加えて、CQ系ダンジョンが生成されます（各種CQモブと固有ボスつき）。

### ダンジョン種別

| 構造物 | 出現Mob | ボス |
|---|---|---|
| 石塔（TOWER） | スポナー（ゾンビ/スケルトン） | 15%でカタクリズム |
| 地下石室（CRYPT） | 洞窟グモスポナー・TNT罠 | — |
| 海賊船（Ship） | 海賊×4（弓手=リボルバー持ち） | 海賊船長 |
| 砂漠の砦（Pyramid） | ミイラ×4（槍兵含む） | ファラオ |
| 氷原の城（Snow Castle） | ウォーカー×5（衛兵/槍兵/弓兵混成） | ウォーカーキング |
| ネクロマンサーの城（Keep） | 武装スケルトン×5+メイジ | ネクロマンサー |

### 武装Mobの特性（CQ再現）

- 鎧・武器で武装した人型Mob。**瀕死（HP25%以下）で一度だけ逃走し回復ポーションを飲み+10回復**します。
- 兵科: 戦士/弓兵/槍兵/衛兵（被弾半減）/バーサーカー/ニンジャ（背後被弾2倍）/ヒーラー（仲間を回復）/バナーマン（仲間に速度・攻撃・耐性II付与）/メイジ/フックマン。
- 撃破で種族ドロップ+低確率でエメラルド・ラピス・金塊・装備品。

### CQボス（`/nb cqboss <id>` で召喚可能）

| ボス | HP | 特徴 |
|---|---|---|
| ネクロマンサー | 300 | 吸血弾連射・スケルトン召喚 |
| リッチ | 300 | 吸血弾+接近者を衝撃波で吹き飛ばす |
| ウォーカーキング | 500 | 突風押し戻し・背後テレポート・被弾時40%軽減+反射 |
| 海賊船長 | 500 | 背後テレポート+短時間透明化 |
| ファラオ | 400 | 地揺れ（周囲を打ち上げ+8ダメ） |
| 亡霊の君主 | 400 | 恒常透明・20秒毎に5秒間だけ実体化（攻撃可能な隙） |
| ジャイアントスパイダー | 450 | 3倍サイズ・糸で引き寄せ+強毒30s・被弾時攻撃者鈍足 |
| モンキング | 760 | 2倍サイズ・地揺れスラム |

撃破報酬: 固有バッジ（or ヴォイドコア）+ダイヤ+討伐者に3,000 DL。ネクロマンサーは確率で「呪われた骨」、海賊船長は「ニンジャダガー」も落とします。

### CQ武器の使い方

- **ダガー系**: 背後から攻撃で2倍ダメージ。右クリックでガード。ニンジャ/トリックスターは透明化・Shift+右クリックで瞬移。
- **スピア系**: 右クリックで前方一線を薙ぎ払い。ガンスピアは貫通弾、ファイアスピアは炎上。
- **グレートソード系**: 右クリックで正面範囲に大ダメージ+吹き飛ばし。
- **フックショット**: 20m先の敵を手元へ引き寄せ。**リボルバー**: 3秒間隔の射撃。
- **杖系**: 回復/火球/落雷/吹き飛ばし/吸血/毒/拘束 — 右クリックで発動。誰でも使えます。

アイテムID一覧は [ITEMS.md](./ITEMS.md) の Chocolate Quest 節を参照。

## 6. 生活側の知識（world_life）

魔法陣営でも以下は利用可能です。

- **一括破壊**: 斧=原木+葉、ツルハシ=鉱石鉱脈、シャベル=土砂系をまとめて破壊（上限128ブロック・耐久消費）。※`world_life`限定
- **経済**: `/balance` でDL確認、`/pay` で送金。初期残高1,000 DL。
- 科学タグのアイテムは拾えません。科学陣営の仲間に資源加工を任せる連携プレイがおすすめです。

## 7. よくある注意点

- 呪文書/魔導書は **Mage以外が使うと拒否**されます。
- 詠唱GUIは間違えるとシーケンスが最初に戻るので焦らず順番どおりに。
- 職業の変更は原則できません（有償リセット機構あり）。
- 魔法側にも `/skill` 直発動があるため、書物を失っても呪文自体は使えます。
- その他のアイテム全一覧（科学側含む）は [ITEMS.md](./ITEMS.md) を参照。
