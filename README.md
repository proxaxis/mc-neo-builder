# Neo Builder Plugin for Minecraft Paper Servers

ようこそ! このプラグインは、BuildCraft、LogisticsPipes、IC2 などの往年の名作工業 MOD、本格アクション RPG、経済システムをシームレスに体験できる複合プラグインです. サーバ参加時に自動適用される専用リソースパックにより、精巧な 3D モデルのマシン、滑らかなパイプ輸送、カスタム GUI、迫力のボスバトルを再現しています. 

## 1. はじめに

本プラグインは Minecraft Java Edition (Paper MC) 向けに最適化されていますので、クライアント MOD は必要ありません. ただし、ゲームの快適なプレイには専用のリソースパックの有効化が必要ですので、サーバ参加時には確認をお願いします.

## 2. 基本規格

ワールドには、統一された 3 つの単位を中心としたエコシステムがあります. 

### 2.1. `MJ` - `Minecraft Joules`

* 基本となるエネルギー単位です. 
* エンジンや発電機で生成され、電線やキネシスパイプを通じてマシンに供給されます. 
* 粉砕機、採掘機、ポンプなどの稼働に必須です. 

### 2.2. `DL` - `Minecraft Dollar`

* 基本となる経済単位です.
* プレイヤー間取引、ショップでの売買、土地の開放や維持などに使用されます. 

### 2.3. `EFP` - `Minecraft Environmental Foot Print`

* プレイヤーの活動によって環境に与える影響を表す環境負荷指数です.
* 環境負荷をかけるプレイヤーは相応の対価を払わなければいけません!

> [!NOTE]
> `MJ` と `DL` は直接変換できません.

## 3. 工業システム

### 3.1. 動力とエンジン

* Redstone Engine: レッドストーン信号のみで動く低出力エンジン. パイプからのアイテム抽出に最適です.
* Stirling Engine: 石炭や木炭を燃料とする中型動力. 序盤の粉砕機やポンプの稼働に使用します.
* Combustion Engine: 冷却水と精製油などの燃料を消費して高出力を生み出す大型エンジンです.
* Compact Engine: 省スペースで高出力を実現する発展型エンジンです. 小さくて便利ですが、環境負荷や爆発リスクなどとトレードオフです.

### 3.2 パイプと配送

* Transport Pipes: アイテムを搬送します. 木、石、鉄、金、ダイヤ、黒曜石など、材質ごとに分岐、加速、吸引の特性があります. 
* Teleport Pipes: 離れた拠点間やディメンションを越えてアイテム、液体、エネルギーを瞬時に無線転送します.
* Logistics Pipes: リクエストパイプやプロバイダーパイプを接続することで、チェストの中身を検索して手元へ自動納品したり、中間素材から完成品までのオンデマンド自動クラフトを実現します.

### 3.3. 採掘と整地と加工

* Quarry: 指定エリアを岩盤まで全自動採掘します. 動作にはエネルギーと広い土地が必要です.
* Filler: 整地、穴埋め、指定ブロックの置換を一瞬で行う建築補助マシンです.
* Macerator: 鉱石を粉砕して粉に変換します. かまどで焼くことで鉱石を効率的に精錬することができます.

## 4. ロールプレイングシステムとスキルシステム

プレイヤーは自分のプレイスタイルに合わせた職業を選択し、スキルツリーを解放できます.
専用ワールドを冒険してお金を稼ぎましょう!

* Warrior: 戦士です. 高い近接火力を持ちます. 
* Guardian: 守護者です. 高い耐久性能を持ちます.
* Mage: 魔道士です. 呪文書を用いた魔法攻撃能力を持ちます.
* Archer: 弓使いです. 本クラスを持つ者だけが弓を使用できます. 

> [!WARNING]
> 職業のリセットにはコストがかかります. 慎重に選びましょう!

## 5. 生活ユーティリティ

作業のストレスを減らし、工業や農業に集中できる便利機能を搭載しています. 

* CutAll Utility: 斧で原木を壊すと、繋がっている原木と葉を一括で伐採. 
* MineAll Utility: ピッケルで鉱石を壊すと、鉱脈を一括で採掘.
* DigAll Utility: シャベルで土、砂、砂利を一括掘削.

> [!WARNING]
> これらのシステムはオーバーワールドのみで有効です.

## 6. ダンジョンと強化ボス

通常ワールドとは別に、凶悪なトラップと強力なモブが潜む自動生成ダンジョンが存在します.

* 強化型モブ: 防具をまとったゾンビの群れ、特殊矢を放つスケルトン、爆発範囲の広がったクリーパーが出現. 

* カタクリズム・ボス（Cataclysm Bosses）:

  * 独自の連続攻撃、薙ぎ払い、レーザー放射、ノックバック無効化を持つレイド級ボス. 

  * 討伐することで、工業の最上位素材（Void Core等）や、固有スキルを持つ伝説の武器・防具をドロップ. 

## 7. 初心者向け序盤の手引き（Progression）

1. 木を伐採し、職業を選択する:

   * `/job join` で好みの初期職業を選びます. 

2. 鉱石を集めて基本ツールを作る:

   * MineAllを活用して鉄・銅・錫を確保. 

   * レンチ（Wrench）と木製ギア（Wooden Gear）をクラフト. 

3. 最初の機械を作る:

   * 粉砕機（Macerator）を作り、鉱石の2倍化サイクルを確立. 

   * スターリングエンジンを作成してMJ動力を供給. 

4. 自動化と拠点防衛:

   * チェストと木パイプ・石パイプを繋ぎ、かまどへの自動搬入ラインを構築. 

   * 夜間や地下の強化モブに備え、スキルポイントを割り振ってステータスを強化. 

5. クァーリーとダンジョン攻略へ:

   * 資源採掘ワールドでクァーリーを稼働させ、潤沢な資源をもとに上級防具を作成. 

   * 仲間と共にダンジョンへ挑み、ボスの撃破を目指しましょう！

## 8. 主なコマンド一覧

| コマンド | 説明 | 
| `/menu` | サーバー総合メニュー・機械レシピガイドを開く | 
| `/skills` | スキルツリーの確認とポイント割り振り | 
| `/job` | 職業情報の確認・転職 | 
| `/money` (または `/bal`) | 所持ドルの残高確認 | 
| `/pay <player> <amount>` | 指定プレイヤーへ送金 | 
| `/all toggle` | 一括破壊（CutAll/MineAll等）のON/OFF切り替え | 
| `/spawn` | メイン拠点のスポーン地点へテレポート | 
| `/rtp` | 資源採掘ワールドのランダム地点へテレポート |
